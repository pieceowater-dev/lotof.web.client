# Сравнение функционала lota и конкурента

Источник по конкуренту: подробный разбор его кода и интерфейсов (разделы 1–34 внутреннего описания функционала; здесь он везде называется «конкурент»). Hub не сравнивается. Atrace сравнивается только там, где у конкурента есть аналог (зарплата, смены).

Обозначения: ✅ есть и не хуже · ◐ есть частично · ⛔ нет, делаем · ❌ нет и не делаем (осознанно) · ➕ есть у lota, у конкурента нет.

Итог в одной строке: по ядру сервисного центра (заказы, клиенты, склад, задачи, доставка) lota закрывает около 85–90% функционала конкурента; осознанно не берём глубокие права, матрицу переходов, колл-центр «как у них» и районы/тарифы доставки; не хватает отдельного финансового модуля (кассы, статьи, движение денег) и крупных платформенных вещей (демо-режим, хранилище по пространствам в консоли).

## 3. Финансы

| Функция конкурента | lota | Комментарий |
|---|---|---|
| Кассы с остатком, доступ по пользователям | ◐ | кассы и смены — в Goods; остаток после каждой операции, X/Z-отчёт ✅ |
| Статьи прихода/расхода, группы, «движение денег», «все деньги» | ⛔ | в бэклоге, не начато; отдельного финансового модуля нет; есть касса POS, оплаты заказов и отчёты Goods |
| Перемещение денег между кассами | ⛔ | |
| Защита от дублей платежа | ✅ | ключи идемпотентности |
| Платёж сотруднику (аванс, зарплата) | ◐ | зарплата и штрафы — Atrace; выплата не привязана к кассе |

Вывод: это самый заметный функциональный разрыв. Решение — выделить в бэклог «Финансы» (статьи, связь с кассами Goods, отчёт «движение денег»), в этот заход не входит.

## 10. Что у lota сильнее

- Платформа из независимых приложений, единые вход и биллинг, сборки.
- Онлайн-запись (Plans), публичная витрина и каталог, лояльность и бонусы по компаниям, абонементы.
- Учёт сотрудников (Atrace): график, посещаемость, зарплата, штрафы.
- Три языка интерфейса, вход только через Google.
- Единый стек (Go + gRPC, GitOps), стоимость владения около $160 в месяц.

## 11. Итог: чего не хватает до «всё, что нужно»

В бэклоге (не начато): финансовый модуль (статьи, движение денег), настраиваемые кнопки доставки, льготный период и бан в Capital.

Не делаем (решение владельца): партии FIFO, видео гида, напоминания о сроках, серверные фильтры по полям и автору, запись звонков, глубокие права, WhatsApp.
