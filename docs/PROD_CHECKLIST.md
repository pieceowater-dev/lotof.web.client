# Список фич для проверки на проде

Перед проходом: в Goods → Настройки → Общие включить «Наличные по заказам — в кассу» и «Резервировать детали под заказ», перезагрузить страницу и убедиться, что переключатели остались включены (раньше не сохранялись). Нужны Goods gtw `7c186b4` и Goods msvc `4c6ad7c`.
