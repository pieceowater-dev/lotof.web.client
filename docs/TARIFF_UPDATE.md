# Тарифы и продовой каталог: что нужно проверить и поменять

**Статус: на проде НЕ применялось.** Тарифы и лимиты хранятся в базе Capital и редактируются только из консоли администратора (запрос `plans` закрыт авторизацией). У меня нет доступа администратора к проду, и выпускать токен вручную из секретов кластера я не стал: это обход авторизации, а не «обновление тарифов». Поэтому ниже — точный список для применения в консоли (Консоль → Биллинг → Тарифы / Сборки).

## 1. Что изменилось в продуктах и как это связано с тарифами

| Что появилось | Нужно ли менять тариф |
|---|---|
| Вложения к комментариям заказа Menu (фото, PDF, Word, Excel, txt, csv) | Они считаются в `storage_mb` Menu. Проверьте, что у каждого тарифа Menu задан `storage_mb` (иначе лимита нет вообще). Значения подберите под ваши тарифы; ориентир по возрастанию: 500 МБ, 2 ГБ, 10 ГБ |
| Комментарии и фото в Issues, заметки Contacts | уже считаются в `storage_mb` своих приложений: проверить ту же вещь |
| Платёж заказа → касса Goods | отдельного лимита нет; требует у тарифа Goods возможности «Касса» (`max_registers` ≥ 1) |
| Деньги и курьер в задачах доставки, режим «закрывать, когда выполнили все» | лимитов нет |
| Отчёты Menu (исполнители, время в статусах, по полю, журнал) | лимитов нет |
| Категории шаблонов документов, суммы 00.00 | лимитов нет |
| Динамические поля клиента с подсказкой и значением по умолчанию | `max_custom_fields` уже есть; новых ключей нет |
| Остаток позиции в форме заказа (Menu ↔ Goods) | лимитов нет; работает, если у пространства подключены оба приложения и в Goods задан склад по умолчанию |

## 2. Текст возможностей на тарифах (то, что видит клиент)

Добавьте строки в «Что входит» (ru / en / kk — три языка обязательно, иначе заголовок `plan-limits-bin` покажет пустой текст):

- Menu: «Комментарии и файлы в ленте заказа», «Отчёты по исполнителям и статусам», «Согласование цены клиентом по ссылке».
- Goods: «Наличные заказов в кассу», «Печатные формы документов», «Инвентаризация по штрихкоду».
- Issues: «Доставка: деньги и курьер в задаче».
- Contacts: «Подсказки и значения по умолчанию в полях клиента».

## 3. Проверка после правки

1. Консоль → Биллинг → тарифы: у каждого приложения заполнен `storage_mb`.
2. Страница `/{пространство}/plans`: тексты возможностей показываются на всех трёх языках.
3. Загрузите вложение в комментарий заказа на тарифе с маленьким лимитом: при превышении должно быть понятное сообщение, а не «internal error».

Дайте токен администратора платформы (в переменной окружения на одну сессию) или подтвердите, что можно временно выдать себе служебный доступ — я внесу правки через консольный API и положу в репозиторий скрипт и откат.
